# Command Palette

Open with Ctrl+K or slash outside inputs; Escape closes. Arrow keys select, Enter opens, Ctrl+Enter opens another tab. Commands are ranked with Fuse.js, with exact symbols and mnemonics prioritized.

Examples:
- AAPL changes the active security.
- AAPL FIN opens AAPL financial statements.
- MSFT GP opens its chart.
- PORT, STRESS, BACKTEST, DROP, EXCEL and HEALTH open their workspaces.
- BT and XLS aliases resolve through the registry.

Results display scope and implementation status. Unsupported/provider-dependent entries open an honest availability state. Security and function results are searchable by symbol, name, category keywords and aliases.

Not implemented: dataset/job/note search, AI natural-language interpretation and arbitrary command chaining. The palette does not execute trades or arbitrary code.
