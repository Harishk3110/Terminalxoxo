# API

Current API endpoints:

- `GET /health/live`
- `GET /health/ready`
- `GET /metrics`
- `GET /api/environment`
- `POST /api/auth/setup`
- `POST /api/auth/login`
- `GET /api/public/content`
- `GET /api/market/securities`
- `GET /api/market/security/{instrument_id}`
- `GET /api/portfolio`
- `GET /api/risk`
- `GET /api/options/{instrument_id}`
- `GET /api/providers`
- `GET /api/broker/status`
- `GET /api/jobs/events`

Production deployments should restrict interactive API documentation.
