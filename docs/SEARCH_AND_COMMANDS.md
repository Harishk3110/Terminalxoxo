# Search and Commands

The terminal command search is backed by `@knk/terminal-functions`. Initial functions include `HOME`, `DES`, `GP`, `FIN`, `DCF`, `OPT`, `PORT`, `RISK`, `HEDGE`, `EDGE`, `BT`, `PINE`, `XLS`, `PPT`, `HEALTH`, and `CONN`.

Search is local and deterministic in demo mode. Provider-backed security search can be added behind the same typed interface.
