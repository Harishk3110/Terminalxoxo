# IBKR Paper Setup

1. Install TWS or IB Gateway.
2. Use a paper account.
3. Enable API access in read-only mode.
4. Keep the socket bound to localhost or a trusted local address.
5. Start `services/broker-agent`.
6. Pair the device from Settings > Broker Agent.
7. Confirm the terminal shows `PAPER` and read-only status.

The broker password is never entered into KnK Capital Terminal.
