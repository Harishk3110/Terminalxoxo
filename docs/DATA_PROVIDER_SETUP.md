# Data Provider Setup

Providers start in `DEMO` mode. To connect a provider:

1. Open Settings > Connections.
2. Enter credentials into the secure connection form or environment-backed secret store.
3. Test the connection.
4. Confirm entitlements.
5. Run initial backfills.
6. Verify timestamps and data-quality labels.

Datasets not covered by the provider stay labelled as demo or unavailable.
