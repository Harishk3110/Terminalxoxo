# Portfolio-First Operating Model

KnK Capital Terminal retains the approved compact black/amber shell. HOME is
the Portfolio Command Centre for KNK_MAIN, KnK Capital Main Portfolio, SGD
70,000 proprietary reference capital, manual execution and initial IBKR Paper
mode. No external-client accounting or order transmission is provided.

## Delivered Workflows
- Explicit opening contribution, native-currency cash and ledger-derived holdings.
- Decimal NAV, immutable valuation records, performance, risk and reconciliation.
- Operating desks: Portfolio, Equity, Quant, Risk & Trade, Research, Data, System.
- Thirteen-metric ribbon; NAV/benchmark/flow/drawdown chart; positions,
  attribution, trades, strategy registry and operating exceptions.
- Browser CSV/XLSX/JSON inbox, twelve mapping profiles, explicit approval,
  versioned curated datasets and source-aware prices/fundamentals.
- Outbound local file agent with revocable scopes and OS-vault credentials.
- Trade review, source preferences, workbook reports and candidate registry.

## Boundaries
The application is a manual research and accounting terminal. An optional
outbound paper-account reader supports scoped snapshots and explicit fill
approval. Actual TWS connectivity is unverified. Verified paper performance,
arbitrary strategy execution and automatic candidate promotion are not enabled.
Existing broker demonstration endpoints are not a connected IBKR account. Provider-required
functions remain labelled. See PORTFOLIO_ACCEPTANCE.md for verification and gaps.
