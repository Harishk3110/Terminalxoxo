# Data Dictionary

- `quality`: data-quality state such as `DEMO DATA`, `PAPER`, `CONNECTED`, `STALE DATA`, or `PROVIDER UNAVAILABLE`.
- `effective_timestamp`: timestamp the value represents.
- `ingestion_timestamp`: timestamp the platform received or generated the value.
- `provider`: source system or fixture provider.
- `dataset`: named dataset within the provider.
- `methodology`: calculation or ingestion method used.
- `base_currency`: portfolio reporting currency, initially `SGD`.
- `reference_capital`: initial KnK Capital reference capital, initially `70000`.
